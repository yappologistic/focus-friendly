# Contributing

Thanks for helping make information easier to use.

## Good contributions

- A real example where the skill reduced or increased cognitive load
- A clearer instruction with the same meaning
- A source-backed accessibility improvement
- A test case for a reading, learning, research, or project workflow
- A fix that preserves technical accuracy and user agency

## Before changing behavior

1. Describe the barrier in one sentence.
2. Show a before-and-after example.
3. Explain which users may benefit or be harmed.
4. Avoid universal claims about ADHD.
5. Add or update a manual test in `docs/TESTING.md`.

## Validate

Run the validation commands in `docs/TESTING.md` and review the skill with at least one realistic prompt.

## Commit style

Use small commits with direct messages, for example:

```text
feat: add focus recovery workflow
docs: clarify clinical boundaries
test: cover full-detail reading requests
```
