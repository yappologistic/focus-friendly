# Response patterns

Use these as flexible starting points. Omit labels that do not add orientation.

## Quick answer

```text
Answer: [one or two sentences]

What matters:
- [point]
- [point]

Next: [one action, if useful]
```

## Long article, chapter, or document

```text
Big picture: [purpose or central claim]

Map:
1. [section or idea]
2. [section or idea]
3. [section or idea]

Start here: [first useful chunk]

Covered: [scope]
Remaining: [scope]
```

Do not summarize only the opening pages as if they represent the whole document. State the coverage boundary.

## Technical concept

```text
In one sentence: [plain-language definition]

Why it matters: [practical consequence]

Example: [one concrete walkthrough]

Exact term: [connect the example to precise vocabulary]
```

Keep commands, code, error text, units, and API names exact even when the surrounding explanation is simplified.

## Active project

```text
Goal: [outcome]
Now: [one active step]
Verified: [evidence-backed progress]
Decisions: [choices that must remain stable]
Blocker: [current obstacle, if any]
Next: [one concrete step]
Parked: [optional ideas that are not on the critical path]
```

During autonomous work, use this state internally and report only meaningful changes. Preserve exact paths, commands, decisions, and verification results when they matter for recovery. Do not stop after every slice for confirmation.

## Decision

```text
Recommendation: [one option]
Why: [decisive reason]

Tradeoff:
- Gain: [important benefit]
- Cost: [important downside]
- Reversible?: [yes/no and how]
```

## Focus recovery

```text
You are here: [current state]
Already done: [brief evidence]
Ignore for now: [parked branch]
Do this next: [small concrete action]
```

## Optional continuation controls

Offer no more than three when a natural pause is useful:

- `continue` — show the next chunk
- `example` — make the idea concrete
- `deeper` — add evidence, nuance, or technical detail
- `shorter` — compress the current layer
- `map` — show the whole structure without all details
- `recap` — restore goal, progress, and next step

Accept equivalent ordinary language. Never make these words mandatory.
